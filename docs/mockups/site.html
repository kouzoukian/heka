Use your DualSense or DualShock 4 as an Xbox or PS4 controller in Windows games.

heka is a tray app. It creates a Virtual Controller that games see in place of your Controller, and hides the real one so they do not see it twice.

Download for Windows v0.2.0 · 10.3 MB Download from GitHub Releases How to install
  • Windows 10 or 11, 64-bit
  • Portable zip, no installer
  • Free and open source, no telemetry

Install heka

  1. Install the drivers

    Use their official installers, and restart Windows if asked.

    ViGEmBus Required Creates the Virtual Controllers. Its author retired it in 2023, so it gets no further updates. Get ViGEmBus
    HidHide Recommended Hides Controllers from games. Without it, games may see each Controller twice. Get HidHide

  2. Download and extract heka

    Extract the zip to a folder you will keep.

  3. Close other controller tools

    DS4Windows, DualSenseX and Steam Input compete with heka. See conflicts.

  4. Run heka.exe

    It is not code signed, so Windows SmartScreen may warn the first time: choose More info, then Run anyway.

  5. Connect your Controller

    It is Bridged automatically, as an Xbox controller until you choose otherwise. To pair over Bluetooth, hold PS and Create (DualSense) or PS and Share (DualShock 4) until the light bar flashes, then add it in Windows' Bluetooth settings.

DualShock 4 support is experimental. It has never been tried on a real one. Report what works and what does not.

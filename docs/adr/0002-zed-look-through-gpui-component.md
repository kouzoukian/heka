# Zed look through gpui-component

The interface follows Zed's layout and density with the Min Dark (Solid) theme (MIT, from Miguel Solorio's Min Theme and its Zed port), built with `gpui-component`. It first used Zed's One Dark; the maintainer chose Min Dark instead. Zed's own `ui` and `theme` crates are GPL-3.0-or-later and unpublished, so using them would force heka off its MIT OR Apache-2.0 license and pull in much of Zed.
